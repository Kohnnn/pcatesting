# SentimentAlpha Vietnam

Trading signals platform for Vietnamese stock market based on analyst recommendations and sentiment analysis.

## Quick Start

```bash
manage.bat
# Select option 1 to start both servers
```

Then open http://localhost:3000

## Documentation

- **[progress.md](progress.md)** - Development status and roadmap

## Requirements

- Python 3.8+
- Node.js 16+
- Windows OS (for batch scripts)

## First Time Setup

```bash
manage.bat
# Select option 2 for full setup
```

This will:
1. Install Python dependencies
2. Install Node.js dependencies
3. Initialize the database

## Features

- 📊 Trading signals based on academic research
- 📈 Sentiment analysis using 5 technical indicators
- 💼 Portfolio watchlist management
- 🗄️ Data pipeline for Excel file processing
- 🌓 Dark/light theme support
- 📱 Responsive design
